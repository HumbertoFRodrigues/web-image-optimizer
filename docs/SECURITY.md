# Security Notes

- Nunca confie apenas na validação feita pelo browser.
- Valide o MIME/type e o conteúdo no servidor.
- Defina limites de upload.
- Não permita execução de scripts dentro do diretório de uploads.
- Remova metadados quando a privacidade for importante.
- Evite nomes de ficheiro fornecidos diretamente pelo utilizador.
- Para arquivos que precisam ser preservados, mantenha o original fora do webroot.
