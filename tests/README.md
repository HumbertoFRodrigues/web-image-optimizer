# Tests

Use imagens reais para validar:

- JPEG grande
- PNG com transparência
- foto tirada ao alto
- foto tirada de lado
- GIF animado
- imagem já pequena
- imagem acima de 1920 px
- imagem com EXIF/GPS

Os testes devem confirmar dimensões, formato, tamanho final, orientação e preservação de transparência.
